# calculator

PHP-CLI로 작성된 8-bit 사칙연산 계산기입니다. <br>
정수에 대한 덧셈 및 뺄셈을 지원합니다.

A 8-bit math calculator written in PHP-CLI. <br>
You can add and subtract integers.

## app-cli.php

```
$ php app-cli.php
```

## app-gui.php

<a href = "https://github.com/gabrielrcouto/php-gui"> php-gui </a>라이브러리로 구현한 테스트용 GUI 애플리케이션 <br>

```
$ composer require gabrielrcouto/php-gui:dev-master
$ php app-gui.php
```
